A [make.fun](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty entry for "Monday Morning Punchlines".

`main.py` writes one Monday-morning joke (under 200 characters) to
`/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set)
and prints it:

> I set three alarms for Monday morning. My bed defeated all three, my coffee surrendered, and I arrived at work as a cautionary tale.

Run it with:

```sh
python3 main.py
```
